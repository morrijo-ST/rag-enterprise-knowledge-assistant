# Enterprise RAG Knowledge Assistant

A public-safe retrieval-augmented knowledge assistant that searches a synthetic policy/operations corpus, returns relevant passages, and shows source citations for every answer.

## Demonstrates
- document chunking and retrieval
- metadata filtering
- source citations
- confidence / relevance scores
- grounded answer generation patterns
- unsupported-question handling

All documents are synthetic.

## Run
```bash
pip install -r requirements.txt
streamlit run app.py
```
